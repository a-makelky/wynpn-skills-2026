# WYNPN Skills 2026

A shared library of agent skills built by Wyoming nonprofit professionals, for Wyoming nonprofit professionals.

Started at the **2026 Wyoming Nonprofit Network Conference** (Casper, May 19–21) in the workshop *Creating Customized AI Tools That Work with Teams*.

---

## What's in here

Each `.md` file in this repo is one **agent skill:** a plain-text instruction file you can paste into ChatGPT, Claude, Gemini, or any other AI tool to make it do a specific job for your organization.

Three starter skills to get you going:

- **[grant-narrative-drafter.md](grant-narrative-drafter.md):** Turn program details + funder priorities into a first-draft grant narrative
- **[board-report-summarizer.md](board-report-summarizer.md):** Compress raw program/financial data into a tight one-page board update
- **[donor-thank-you-generator.md](donor-thank-you-generator.md):** Write personal, non-generic thank-you notes that don't sound like a form letter

Plus a starter template:

- **[SKILL_TEMPLATE.md](SKILL_TEMPLATE.md):** Copy this when you build your own skill

---

## How to use a skill

1. Open the `.md` file in this repo
2. Copy everything from the top of the file (including the `---` block) to the bottom
3. Paste it into a new chat with your AI tool of choice (ChatGPT, Claude, Gemini, etc.)
4. Hit enter. The AI is now configured to do that one job
5. Give it your specifics ("here's our program description, the funder is XYZ Foundation, word limit 1,000")

---

## How to contribute your own skill

1. Build your skill. Start from [SKILL_TEMPLATE.md](SKILL_TEMPLATE.md)
2. Save it locally with a descriptive name (e.g., `volunteer-onboarding-email.md`)
3. In this repo on GitHub, click **Add file → Upload files**
4. Drag your file in, scroll down, write a short note in the commit message (e.g., "Adding volunteer onboarding email skill")
5. Click **Commit changes**

That's it. Your skill is now in the team library.

---

## Why skills, not prompts?

A prompt lives in one person's chat history and dies when they close the tab. A skill lives in a file, gets shared with your team, and works the same way no matter who runs it or which AI tool they use.

Same file. Same output. Across people, across tools, across time.
